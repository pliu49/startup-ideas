# 客户看板字段说明（Notion / Airtable 通用）

用 `clients-board-seed.csv` 直接导入 Notion（Import → CSV）或 Airtable（Add table → Import data），
会自动按下面的字段建好表，并带一行案例数据。导入后把各字段类型改成建议的类型即可。

| 字段名 | 建议类型 | 说明 / 可选值 |
|---|---|---|
| 客户名称 | 标题（Title） | 对应 `clients/<客户名>/` 文件夹名 |
| 当前阶段 | 单选（Select） | 评估中 / 已发评估报告 / 注册对接中 / 建站中 / 已上线运营中 / 暂停 |
| 套餐档位 | 单选（Select） | 验证版 / 标准版 / 全案版 / 待定 |
| 负责人 | 人员/文本 | |
| 目标市场 | 文本 | 例如"美国" |
| 品类 | 文本 | 例如"平板配件" |
| 评估报告 | 链接/文件 | 指向 `clients/<客户名>/report.pdf` 或分享链接 |
| 独立站链接 | URL | 上线后填 |
| 下一步动作 | 文本 | 例如"等客户确认预算" |
| 最近更新日期 | 日期 | 每次跟进后手动更新 |
| 备注 | 文本 | |

## 使用建议

- **看板视图（Board view）** 按"当前阶段"分组，就是一个简易 Kanban，一眼看出每个客户卡在哪一步。
- **表格视图（Table view）** 按"最近更新日期"排序，用来做每周回顾，找出太久没跟进的客户。
- 这个看板只做"客户状态追踪"，具体的问卷/报告内容仍然存在本地 `clients/<客户名>/` 文件夹里（Git/OneDrive 会自动备份），看板里只放链接，避免两处内容不同步。
