# 出海方案工作室 — 内部工具

帮中国卖家/工厂做"美国主体注册对接 + DTC独立站搭建 + 上线运营"的内部顾问工具。
服务结构：四阶段（出海评估 → 公司注册对接 → 独立站搭建 → 上线运营）× 三档套餐（验证版/标准版/全案版）。

这套工具目前只自动化了 **阶段① 出海评估**，其余阶段先手动跟进，验证完模式后再考虑加自动化。

## 新客户进来了，怎么跑这套流程

1. **记录问卷**：沟通时对照 `templates/intake-template.md` 记录信息（不用填满，缺的字段留空）。
2. **建客户文件夹**：复制问卷，另存为 `clients/<客户名>/intake.md`。
   （命名建议用日期+客户简称，例如 `clients/2026-09-22-华南电子厂/intake.md`）
3. **生成评估报告初稿**：在 Claude Code 里对着这个项目说
   > 用 assess-client 技能给 `<客户名>` 生成评估报告
   会自动读取该客户的 `intake.md`，研究同品类的真实独立站案例，产出 `clients/<客户名>/report.md`。
4. **人工审核**：这份报告是初稿，必须自己通读一遍——尤其是主体注册建议和竞品数据，
   确认没有编造信息、免责声明没被删掉，再做润色。
5. **导出发给客户**：审核通过后，让 Claude 用 `pdf` 技能把 `report.md` 转成 `report.pdf` 发给客户。
6. **登记看板**：在 Notion/Airtable 客户看板（见 `board/notion-schema.md`）里加一行，更新阶段和下一步动作。

## 目录说明

```
templates/          问卷 & 报告的空白模板，新客户从这里复制
clients/            每个客户一个文件夹，装 intake.md 和 report.md
  _example-monsterdangdang/   案例0，怪兽当当项目包装成的参考案例（内部展示/技能测试用）
board/               Notion/Airtable 看板的字段设计 + 可导入CSV
.claude/skills/      assess-client 技能定义
```

## 定位边界（提醒自己）

- 这是**内部工具**，客户不会登录任何系统，只收到报告/独立站链接/邮件。
- 报告里的主体注册、税务相关内容**只是参考建议**，不是法律/税务意见——真正落地要接靠谱的
  registered agent / 会计师，不要自己下场给客户做法律判断。
- 验证版报价可以放低（甚至换案例授权），但不要把低价当成常态定价。
